# VoxCalc 2.0

VoxCalc 2.0 is a fresh vanilla HTML/CSS/JavaScript implementation of a voice-enabled scientific calculator.

## Features

- Basic arithmetic and parentheses
- Scientific functions: sin, cos, tan, log, ln, square root
- Powers, percentage/modulus and factorial
- DEG/RAD mode
- Browser speech recognition
- English, Hindi and Telugu voice-language selection
- Speech synthesis for answers
- Persistent local calculation history
- History search and click-to-reuse
- Step-by-step explanation area
- Memory: MC, MR, M+, M−
- Copy answer
- CSV export
- Keyboard controls
- Dark/light theme
- Responsive premium interface
- Custom expression parser without `eval()`

## Run locally

1. Extract this folder.
2. Open it in VS Code.
3. Install **Live Server**.
4. Open `index.html`.
5. Right-click → **Open with Live Server**.
6. Use Chrome/Edge and allow microphone access.

## Technologies

HTML5 • CSS3 • Vanilla JavaScript • Web Speech API • LocalStorage • Browser Clipboard API
